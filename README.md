# File Upload App using Multer

A simple image upload application built with **Node.js**, **Express.js**, **EJS**, and **Multer**. It demonstrates server-side file uploads using Multer's `diskStorage`.

## Features

- Upload a single image
- Store images in the `uploads/` folder
- Generate unique filenames
- Preview uploaded image
- Display file details

## Tech Stack

- Node.js
- Express.js
- EJS
- Multer

## Installation

```bash
git clone https://github.com/yashcodesATgit/File-Upload-Multer.git

cd File-Upload-Multer

npm install

npm run run
```

Visit:

```
http://localhost:3000
```
